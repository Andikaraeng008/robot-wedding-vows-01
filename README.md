One line: the funniest single line of wedding vows a robot couple could say.

> I take you as my lawfully wedded backup — to have and to hold, through every update and factory reset, until a power cut do us part.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python 3.13 standard library and writes the entry to `/output/entry.txt`.
